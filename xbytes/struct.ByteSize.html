Struct ByteSize 

Source 
pub struct ByteSize(/* private fields */);
Expand description

A byte size: an exact count of bytes (or bits, under the bits feature) that knows how to render itself in binary or decimal units and how to be parsed back from a string.

The count is stored as an Int. Arithmetic operators combine two sizes or scale a size by a scalar; construction goes through of, from_bytes/from_bits, or FromStr.

use xbytes::prelude::*;

let size = ByteSize::of(2, GIBI_BYTE);
assert_eq!(size.to_string(), "2 GiB");
assert_eq!((size * 2).to_string(), "4 GiB");

pub fn of(value: impl Into<Float>, unit: Unit) -> Self

Build a size from a value (integer or float) and a Unit.

The value is scaled into the backing store and truncated to a whole count. Under the default byte store that truncation is the one documented rounding rule to keep in mind: a value smaller than one byte rounds down, so ByteSize::of(1, BIT) is 0 bytes (0.125 truncated). Overflow saturates rather than panicking.

use xbytes::prelude::*;

let size = ByteSize::of(10, MEBI_BYTE);
assert_eq!(size.to_string(), "10 MiB");

let a = ByteSize::of(1.2, GIGA_BYTE);
let b = ByteSize::of(1.3, GIGA_BYTE);
assert_eq!((a + b).repr(Mode::Decimal).to_string(), "2.50 GB");

pub const fn of_int(value: Int, unit: Unit) -> Self

Build a size from a whole value and a Unit, in const context.

The integer twin of of: for whole inputs it produces the exact same value, but takes an Int instead of impl Into<Float> so it stays out of the float backend and can run at compile time. It cannot express a fractional quantity like 1.5 MiB; use of for that. Overflow saturates and a sub-byte value truncates to zero, matching of.

use xbytes::prelude::*;

// Runs at compile time, and equals `of` for whole inputs:
const FOUR_MIB: ByteSize = ByteSize::of_int(4, MEBI_BYTE);
assert_eq!(FOUR_MIB, ByteSize::of(4, MEBI_BYTE));

On the default byte store byte_count is const too, so ByteSize::of_int(4, MEBI_BYTE).byte_count() is a const byte count with no hand-rolled 1024.

pub const fn from_bytes(value: Int) -> Self

Build a size from a raw byte count. Infallible, since bytes are the store unit without the bits feature. (Under bits, this instead returns a Result, as the byte-to-bit multiply can overflow.)

pub const fn bit_count(&self) -> Result<Int, ParseError>

The raw bit count. Fallible without the bits feature, where the byte-to-bit multiply can overflow the store; returns ParseError::ValueOverflow on failure. (Named bit_count, not bits, to leave the short verb for the bits renderer.)

Source

pub const fn byte_count_lossy(&self) -> Int

The raw byte count as an Int, truncating any sub-byte remainder.

Unlike byte_count, whose return type flips to a Result under the bits feature, this is always an infallible const fn returning Int on every feature setting. Reach for it when a caller (especially a const) wants a plain byte count without caring which store the crate was built with.

pub const fn bit_count_lossy(&self) -> Int

The raw bit count as an Int, saturating rather than overflowing the store.

The infallible, feature-stable companion to bit_count, which returns a Result without the bits feature. Always a const fn returning Int.

pub fn repr(&self, mode: Mode) -> ByteSizeRepr

Render this size at the largest prefix whose value is at least one, in the system the mode selects (binary by default, decimal under Mode::Decimal, bit- or byte-denominated, prefixed unless Mode::NoPrefix).

use xbytes::prelude::*;

let size = ByteSize::of(1536, KIBI_BYTE);
assert_eq!(size.repr(Mode::Default).to_string(), "1.50 MiB");
assert_eq!(size.repr(Mode::Decimal).to_string(), "1.57 MB");
Source

pub fn repr_as(&self, unit: impl Into<Unit>) -> ByteSizeRepr

Render this size at one explicit unit, however large or small the resulting number is (unlike repr, which picks the prefix for you).

use xbytes::prelude::*;

let size = ByteSize::of(1, GIBI_BYTE);
assert_eq!(size.repr_as(MEBI_BYTE).to_string(), "1024 MiB");
Source

pub fn iec(&self) -> ByteSizeRepr

Render in binary (IEC, power-of-1024) units: 1.50 MiB. The auto-prefixed default, and the fluent front door to the Format refiners on ByteSizeRepr.

use xbytes::prelude::*;

let size = ByteSize::of(1536, KIBI_BYTE);
assert_eq!(size.iec().to_string(), "1.50 MiB");
assert_eq!(size.iec().long().precision(3).to_string(), "1.500 MebiBytes");
Source

pub fn si(&self) -> ByteSizeRepr

Render in decimal (SI, power-of-1000) units: 1.57 MB.

use xbytes::prelude::*;

let size = ByteSize::of(1536, KIBI_BYTE);
assert_eq!(size.si().to_string(), "1.57 MB");
Source

pub fn bits(&self) -> ByteSizeRepr

Render denominated in bits rather than bytes, binary-prefixed: 12 Mib. For decimal bits, chain from the power-user repr with Mode::Decimal | Mode::Bits.

use xbytes::prelude::*;

let size = ByteSize::of(1.5, MEBI_BYTE);
assert_eq!(size.bits().to_string(), "12 Mib");
